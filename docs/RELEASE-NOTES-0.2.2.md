# AstroLife Knowledge Base 0.2.2

Release date: 2026-11-09

## Changes
- Align the calculation-provenance cards with AstroLife Pro 0.8.5.
- Preserve the bilingual corpus at 136 cards (68 Persian and 68 English) and 25 registered sources.
- Rebuild the versioned manifest and SHA-256 checksums after the card update.
- Bundle the refreshed Persian and English cards and manifest in the desktop application resources.

## Validation
- 136 unique cards; 68 per language.
- All source IDs resolve against 25 registered sources.
- Language parity, evidence labels, license fields and limitations pass.
- JPL structured reference matches its schema; planetary reference contains 8 planets and 5 dwarf planets with units and explicit uncertainty policy.
- Ranker artifact dimensions and 168 maintainer-labelled judgements across 17 bilingual query families validate.

The ranker evaluation is a small, curated seed holdout and is not an independent benchmark. This release does not claim predictive validity for astrology.
